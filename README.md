# Weather Dashboard 🌦️

A real-time weather dashboard built using HTML, CSS, and JavaScript with RESTful APIs.

## Features

- 🔍 Search weather by city name
- 🌡️ Real-time temperature
- 💧 Humidity information
- 💨 Wind speed
- 🌧️ Precipitation data
- 🌤️ Weather condition and description
- ⚠️ Error handling for invalid cities
- 🔄 Refresh weather data
- 📱 Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- RESTful APIs
- Async/Await
- JSON

## API

This project uses the Open-Meteo Geocoding API and Weather API to retrieve real-time weather information.

## How It Works

1. Enter a city name in the search box.
2. The application finds the city's location.
3. Weather data is fetched from the API.
4. The JSON response is processed using JavaScript.
5. Weather information is displayed dynamically on the dashboard.
